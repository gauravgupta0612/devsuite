# DevSuite — Developer Productivity Pack

One install, five focused tools that share the same local analysis engine. Everything runs on your machine; no code is uploaded.

| | Extension | Answers |
|---|---|---|
| 🧭 | **[RepoPilot](https://marketplace.visualstudio.com/items?itemName=gauravgupta0612.repopilot)** | *What is this project?* Architecture, entry points, build commands, modules, dependency map and an onboarding guide with evidence links. |
| 🎯 | **[DevImpact](https://marketplace.visualstudio.com/items?itemName=gauravgupta0612.devimpact)** | *What will my change affect?* Direct and indirect dependents, an impact score and the exact tests to run. |
| 🛡️ | **[CodeGuard](https://marketplace.visualstudio.com/items?itemName=gauravgupta0612.devsuite-codeguard)** | *Is this safe to commit?* A prioritised risk report: secrets, injection, broken imports, removed APIs, missing tests, risky config. Includes an optional pre-commit hook. |
| 🔀 | **[TraceLens](https://marketplace.visualstudio.com/items?itemName=gauravgupta0612.devsuite-tracelens)** | *How does this request flow?* Every API endpoint, traced through handlers, services and repositories to the database and external calls. |
| 🐞 | **[BugTrail](https://marketplace.visualstudio.com/items?itemName=gauravgupta0612.bugtrail)** | *Have I fixed this before?* A searchable history of errors, the edits you made and what fixed them, across all your projects. |

## Where to find them after installing

- **RepoPilot** and **TraceLens** each add an icon to the Activity Bar.
- **DevImpact** (*Change Impact*) and **CodeGuard** (*CodeGuard Risk*) appear in the **Source Control** view.
- **BugTrail** appears in the **Run and Debug** view.
- All five add tools for Copilot agent mode: `#repoOverview`, `#changeImpact`, `#riskReview`, `#traceRequest` and `#bugHistory`.

## Languages

TypeScript/JavaScript, Python, Java/Kotlin, Go, C#, and **IBM i** (RPGLE, SQLRPGLE, CL, DDS, SQL, COBOL).

You can disable or uninstall any single extension from the pack without affecting the others.
